The foundation of modern mathematics is Set Theory, so we will begin with a short introduction to sets! This will be just an introduction, so will not dive deep, rather just obtain what we need in order to dive into our study of the numbers.

Before we dive into formality, let's get a bit of an intuition for sets. When we talk about a "set", all we mean is a group of objects. That's it! Whenever we are talking about a set, imagine a box. This box has the elements of the set inside it. If we take the set $\{2,5,8\}$, imagine a box withg the numbers $2$, $5$, and $8$ inside it. If we take the set $\{\}$, imagine an empty box! If we take the set $\{ 23, \{\}, \{2, 3, 4\} \}$, imagine a large box with $23$ in one corner, an empty box in another corner, and a box containing $2$, $3$, and $4$.

When we now move to the formalism, what we are attempting to do is the following: How can we come up with a mathematical structure, and a set of rules governing that structure, that match our intuition for how the structure should behave? We shall see that this question and approach will be useful not only here but in all areas of this subject and math in general when we attempt to develop a formalism for an intuitive idea, such as the idea of numbers and addition.

::theorem{type="definition" title="Sets"}
A *set* $A$ is any unordered collection of objects, e.g. $\{3,8,5,2\}$ is a set. If $x$ is an oboject, we say that $x$ is an element of $A$ or $x \in A$ if $x$ is inside the set $A$. If $x$ is not in the set, for example $99$ is not in the example set, this is shown as $x \notin A$. Sets can be objects as well, so if $A = \{1,2,3\}$ and $B = \{5,7,\{1,2,3\}\}$, we would say that $A \in B$.
::
